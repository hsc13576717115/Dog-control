# qr_interfaces

[中文](README.md) | **English**

Defines robot state, estimated contacts, support surfaces, plans and execution results. Foot order is FR/FL/RR/RL; targets are foot centers in odom. Measured force is invalid on this sensorless platform; model residuals are separately labelled. Obstacle and mission messages reserve future interfaces, not implemented autonomy.

See [QR development and validation](../../docs/qr/README_EN.md).
