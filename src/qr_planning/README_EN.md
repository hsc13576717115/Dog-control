# qr_planning

[中文](README.md) | **English**

Geometry.hpp provides convex-region admission, support centroids and quintic reference blending. Full model preflight currently lives in PrecisionRuntime outside the update loop. This is not a general foothold-search node. Run the qr_planning CTest suite for geometry and trajectory checks.

See [QR development and validation](../../docs/qr/README_EN.md).
