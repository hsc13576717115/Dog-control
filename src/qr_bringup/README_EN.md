# qr_bringup

[中文](README.md) | **English**

Launches the full-collision Gazebo robot, precision controller and known fixtures. activate_paused.py confirms controller activation before free-running physics. Use precision_step.launch.py with height:=0.03 and gui:=true to inspect a run. Fault-injection arguments are reserved for validation; real hardware is rejected.

See [QR development and validation](../../docs/qr/README_EN.md).
