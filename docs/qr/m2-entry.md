# M2 入口：有限连续换步与机械筛查

[中文入口](README.md) | [English overview](README_EN.md)

**M2 进行中，尚未达到完整机械/障碍门槛。** M1 冻结验收见 [收尾记录](m1-closeout.md)。这里的连续换步不是连续行走或完整越障。

## 新的软件能力

- `qr_planning/finite_sequence`：C++ 非实时有限模板客户端，依次调用既有 `PlanFootsteps` 和 `ExecuteFootsteps`。每一步重新读取状态、预检并等待承载确认；失败、超时或接收拒绝后不发下一步。
- `FiniteTemplate.hpp`：仅接受 `odom`、初始足端位置加偏移的目标定义；四足编号 FR/FL/RR/RL；最多 16 步，单轴初始偏移不超过 100 mm。拒绝非法/非有限值、错误字段和其他坐标系。
- `flat_shift.yaml`：FR→RL→FL→RR，各足相对初始位置前移 25 mm。机身恢复位置沿用现有执行器；它是重新布置四足的测试模板，不是能无限重复的前进行走步态。
- `model/StaticSupport`：独立静态接触力 QP，固定加速度为零，检查浮动基座平衡、单侧接触、内接摩擦棱锥和规范模型关节力矩限制。无松弛变量；不采用 WBC 软跟踪目标的非零加速度来替代静态平衡。
- `precision_envelope`：复用当前模型、IK、完整腿部/机身对场景碰撞和静态力检查，离线扫描局部困难场景。求解器失败和约束不可行分别记录，不宣称机械不可能。
- ROS action 接收拒绝增加非实时日志 `QR_ADMISSION_REJECT`，标明过期、重放、快照过期、状态不就绪、参考漂移等原因；没有放宽原接收条件。M1 历史的单次拒绝仍不能追溯为某个已证实原因。

规划客户端没有关节命令出口，也不订阅 `/evaluation/*`。真实电机保护仍在原控制器中，精确模式仍禁止真机启动。

## 场景和接口边界

`surface_mode:=ground` 明确发布已知的平地矩形，供 M2 入口测试使用；默认仍为 M1 的双目标面。不是感知地图，不代表未知区域可以填平。

```text
有限模板（odom，初始足端偏移）
  → 当前 RobotState + ExecutionStatus
  → PlanFootsteps：模型预检
  → ExecuteFootsteps：单步执行/实际估计接触确认
  → 完成且 ready 后才进入下一项；否则结束本模板
```

模板只逐步预检，并以可保持的结束姿态作为停止点；**尚未进行整条步序的联合后续可行性搜索**。不能直接用它执行完整桩阵。

## 离线机械筛查的准确含义

每个机身位置尝试 3 个关节初值、2 种足端几何路径，检查 41 个离散点：

- 拱形路径；
- 先抬高、平移、再落下，分段使用五次插值。

静态解去除摆腿接触力变量，避免将“零力固定边界＋摩擦面”重复施加导致的退化 QP。四足平衡、无支撑失败及移重心后三足平衡均有单元测试。

| 局部试验 | 规则参数来源 | 工程假设与限制 |
| --- | --- | --- |
| 平台到单桩 | `rules.yaml` 梅花桩高度/顶面、平台尺寸，规则第6页 | 第一桩中心 `(0.3,-0.2)`、平台边界 `x=0` 为局部试验布局，不声称复现规则全场图 |
| 高墙前腿 | 高 0.30 m、厚 0.08 m、宽 0.80 m，规则第5页 | 只检查前右腿从墙前到墙后；未验证机身和后腿越墙 |
| 沟壑前腿 | 间隙 0.36 m、台面高 0.36 m、台面尺寸，规则第5页 | 用两平台构造局部间隔，足心扣除足半径和边缘裕量；不包含完整台阶/坡道及有效接触覆盖 |

摩擦系数读取现有 `task.info`，质量/关节/足底参数读取规范模型。布局与机身采样范围在扫描报告中保存。没有更改关节限位、删除腿部碰撞或放宽验收阈值。

当前筛查维持机身姿态和位置不动、单前腿移动；尚未包含机身协同平移/俯仰、后腿跟进、连续碰撞检测、自碰撞、动力学过渡和仿真闭环。因此，离散候选也只能用于安排下一轮实验，不能计作障碍成功。

早期 WBC 软目标筛查及退化静态 QP 的结果保留在 `artifacts/rc2027/m2-envelope/`；修复后再次运行，旧的求解器失败不得当作机械证据。

## 复现

按 QR README 构建并 source，然后：

```bash
python3 tools/validate_qr.py --suite m2 --output artifacts/qr/m2-entry
```

套件包括各包单元测试、机械筛查、3 次四足序列、序列首步中注入支撑丢失、四足 50 mm M1 兼容测试和计划重放检查。`status=passed` 表示这些入口测试通过，`stage_accepted=false` 明确表示 M2 的完整门槛仍未通过。

仅启动有限模板测试场景：

```bash
ros2 launch qr_bringup precision_step.launch.py surface_mode:=ground gui:=true
# 另一个已 source 的终端；模板位置按当前仓库根目录：
ros2 run qr_planning finite_sequence --ros-args -p use_sim_time:=true \
  -p template_file:="$PWD/src/qr_planning/config/flat_shift.yaml" \
  -p result_file:=/tmp/qr-sequence-new.yaml
```

输出文件必须不存在。模板结束并不触发下一轮或其他电机控制。
