# QR 开发路线与阶段门槛

[中文入口](README.md) | [English overview](README_EN.md)

当前实现范围为 M0—M1，后续阶段尚未执行。

| 阶段 | 工作 | 验收与风险 |
| --- | --- | --- |
| M0 | RC2027 分支、模型/规则映射、原速度回归、XML 差异报告 | 保留用户资料；模型来源可追踪，场景错误不得计作比赛通过 |
| M1 | IMU/关节接触估计、多高度状态估计、显式 WBC、单腿落点、批量测试 | 四足各 25 次、100 次至少 95 次；P95≤10 mm、最大≤20 mm；滑移≤10 mm、平地姿态偏差≤5°。阈值失败不事后放宽 |
| M2 | 多步模板、局部桩阵、高墙/沟壑机械可行性扫描 | 区分 IK 初值、步序、碰撞、模型与机械限制；验证后腿与后续支撑 |
| M3 | 六桩完整覆盖、高墙、沟壑的已知几何闭环；接入上层约束的 NMPC | 上台阶/桩顶真实足底接触证据、合法进出、尺寸±5%扰动 |
| M4 | 有传感器后再做标定、同步、局部支撑地图、三维碰撞、遮挡置信度 | 未知不补平地；移除场景真值后仍满足误差预算 |
| M5 | 限高/绕桩/桥/坑/轮胎、任务状态机、转场和返航 | 八项独立完成，接触进度/入口出口/原启动区与整机投影检查 |
| M6 | NX 和真实硬件接口校准、反馈周期、热与延迟、逐级受保护实验 | effort 标定、估计触地误差、硬件急停及每阶段实测通过后放行 |
| M7 | 完整场次可靠性、时间优化和有限恢复 | 正常目标150–155秒，统计全部失败；机器人内部完成状态不等于裁判认可 |

状态估计继续在连续 odom；规划与任务非实时；控制器保留唯一关节命令出口。Dog-control 只维护模型式运控，不增加 RL 控制器、策略模型、训练或部署模块。如后续研究方案 C，应在独立的 himloco_custom_dog 工程中实现和验证。

赛前待裁判确认：启动区1尺寸、绕桩必达区判定参考点、有效足底接触定义、入口/出口正常接地范围、轮胎孔内地面接触、启动区2沟壑分项、被动标识和开源复用边界。内部任务管理不能自行替代这些规则解释。
